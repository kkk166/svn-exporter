# SVN Exporter

把 SVN 工作副本里“有变化的文件”单独导出到一个文件夹，并保留原来的目录结构。适合提交前备份、把改动发给同事、制作增量更新包。

扩展提供两个命令：

| 命令 | 导出什么 | 文件内容来自 | 导出到 |
| --- | --- | --- | --- |
| **SVN: 导出变更文件** | 你在本地改过、还没提交的文件 | 本地磁盘 | `目标文件夹\项目名\` |
| **SVN: 导出远程更新文件** | 别人已提交、你还没 `svn update` 的文件 | SVN 服务器 | `目标文件夹\项目名-r版本号\` |

两个命令都只读取，不会修改你的工作副本。

## 使用前提

- 已安装 SVN 命令行客户端，且 `svn` 在 PATH 中（安装 TortoiseSVN 时需勾选 command line client tools）
- VSCode 打开的文件夹是 SVN 工作副本
- 导出远程更新还需要：能连上 SVN 服务器，且账号密码已被 svn 命令行保存（扩展不会弹出密码输入框）

## 安装

**从 .vsix 文件安装**

1. 在 [Releases](https://github.com/kkk166/svn-exporter/releases) 下载最新的 `.vsix` 文件
2. 在 VSCode 扩展视图点击右上角 `...` → **从 VSIX 安装**，选择下载的文件

**从 VS Code Marketplace 安装**

在扩展视图（`Ctrl+Shift+X`）搜索 `SVN Exporter`，点击 **安装**。

## 使用

1. 用 VSCode 打开 SVN 项目文件夹
2. 按 `Ctrl+Shift+P`（Mac：`Cmd+Shift+P`）打开命令面板，输入 `SVN`，选择要执行的命令
3. 选择导出的目标文件夹
4. 等待完成。导出过程会显示进度，可以随时取消

如果安装了提供 SVN 源代码管理的扩展，也可以在 **源代码管理** 面板（`Ctrl+Shift+G`）的标题栏点击对应按钮，鼠标悬停可以看到按钮名称。

工作区里有多个文件夹时，执行命令后会先让你选择要导出哪一个。

## 导出变更文件（本地）

按 `svn status` 的结果决定导出哪些文件：

| 状态 | 是否导出 |
| --- | --- |
| 已修改（M）、新增（A）、替换（R）、冲突（C） | ✅ 导出 |
| 未纳入版本控制（?） | ✅ 导出；如果是文件夹，导出其中所有文件 |
| 已删除（D）、文件丢失（!） | 跳过 |
| 外部定义（X）、忽略项（I） | 跳过 |
| 只修改了 SVN 属性 | 跳过 |

只改属性的文件不导出，是因为属性（如 `svn:eol-style`）保存在 SVN 元数据里，复制文件带不走，导出的内容和仓库里的完全一样。

**示例**

项目结构：

```
D:\projects\myapp\          ← VSCode 打开的文件夹
├── src\
│   ├── main.ts             已修改
│   ├── app.ts              无变化
│   └── utils\
│       └── helper.ts       新增
├── config.json             已修改
└── old.txt                 已删除
```

选择 `E:\backup` 作为目标文件夹，导出结果：

```
E:\backup\myapp\
├── src\
│   ├── main.ts
│   └── utils\
│       └── helper.ts
└── config.json
```

## 导出远程更新文件

不执行 `svn update`，直接从服务器取回远程有更新的文件，方便先看看别人改了什么，或者把最新内容拿去别处使用。

- **导出**：远程新增、修改的文件，内容是远程最新版本
- **跳过**：远程已删除的文件，以及远程只修改了属性的文件
- **本地修改不受影响**：即使某个文件你本地也改过，导出的仍是纯远程版本，本地文件保持原样

导出目录名带有版本号，例如 `E:\backup\myapp-r1240\`。这个版本号是检查时服务器上的最新版本，所有文件都取自这一个版本。

**限制**

- 文件逐个从服务器获取，远程更新很多时会比较慢
- 不支持切换过的子目录（`svn switch`）和外部定义（`svn:externals`）中的文件

## 常见问题

**提示“当前目录不是 SVN 工作副本，或 svn 命令不可用”**

先在终端里进入项目文件夹执行 `svn info`。如果提示找不到命令，说明 SVN 命令行客户端没装好或不在 PATH 中；如果提示不是工作副本，说明 VSCode 打开的不是从 SVN 检出的文件夹。

**目标文件夹里已经有同名文件怎么办？**

会被直接覆盖。想保留旧的导出结果，请换一个目标文件夹。

**提示有文件导出失败？**

导出结束时会汇总成功和失败的数量，并显示第一个失败的原因。本地导出常见原因是目标磁盘空间不足或文件被占用；远程导出常见原因是网络不通或 svn 没有保存账号密码。

**可以只导出某些类型的文件吗？**

目前不支持，会导出全部符合条件的文件。
