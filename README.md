# SVN Exporter

一键导出 SVN 工作副本中所有变更文件，保留完整目录结构。

## 功能

- ✅ 自动检测 SVN 变更文件（M、A、? 等）
- ✅ 忽略 SVN 外部定义（X）和忽略项（I）
- ✅ 自动跳过已删除的文件（D 状态）
- ✅ 导出时保留完整的项目目录结构
- ✅ 导出进度通知，支持取消

## 🚀 快速开始

### 方式一：命令面板（推荐）

1. 在 VSCode 中打开你的 SVN 项目文件夹
2. 按下 `Ctrl+Shift+P`（Mac: `Cmd+Shift+P`）打开命令面板
3. 输入 `SVN`，选择 **SVN: 导出变更文件**
4. 在弹窗中选择要导出到哪个文件夹
5. 等待导出完成，会显示成功提示

### 方式二：SCM 面板按钮

1. 打开 SVN 项目后，点击左侧活动栏的 **源代码管理** 图标（或按 `Ctrl+Shift+G`）
2. 在 SCM 面板标题栏找到 **导出** 按钮（`$(export)` 图标）
3. 点击后选择目标文件夹，等待完成

### 导出示例

假设你的 SVN 项目结构如下：

```
D:\projects\myapp\          ← VSCode 打开的文件夹
├── .svn\
├── src\
│   ├── main.ts             (已修改 M)
│   └── utils\
│       └── helper.ts       (新增 A)
├── config.json             (已修改 M)
└── old.txt                 (已删除 D，不会导出)
```

执行导出并选择 `E:\backup` 作为目标后，会生成：

```
E:\backup\myapp\            ← 自动创建项目名子目录
├── src\
│   ├── main.ts             ✅ 导出
│   └── utils\
│       └── helper.ts       ✅ 导出
└── config.json             ✅ 导出
```

- ✅ 保留完整的项目目录结构
- ✅ 只导出变更的文件（M、A、? 状态）
- ✅ 自动跳过已删除的文件（D 状态）
- ✅ 忽略 SVN 外部定义（X）和忽略项（I）

## 📦 安装

### 从 VS Code Marketplace

1. 打开 VSCode
2. 按 `Ctrl+Shift+X` 打开扩展视图
3. 搜索 `SVN Exporter`
4. 点击 **安装**

### 从 .vsix 文件

1. 下载 `svn-exporter-0.0.1.vsix`
2. 在 VSCode 扩展视图点击 `...` → **从 VSIX 安装**
3. 选择下载的文件

## ⚙️ 要求

- SVN 命令行客户端已安装且在 PATH 中
- 当前文件夹是 SVN 工作副本

## 📝 使用场景

- 🔧 **提交前备份**：导出变更文件到临时目录，方便备份或分享
- 📤 **代码审查**：只导出修改的文件给同事审查
- 🚚 **迁移变更**：将工作副本的变更迁移到另一个环境
- 📦 **打包发布**：只打包有变更的文件用于增量更新

## ❓ 常见问题

**Q: 为什么提示"当前目录不是 SVN 工作副本"？**
A: 确保你打开的文件夹包含 `.svn` 目录，且 SVN 命令行工具已安装。

**Q: 导出的文件在哪里？**
A: 你选择的目标文件夹内，会创建一个以项目名命名的子目录，保持原始目录结构。

**Q: 可以只导出特定类型的文件吗？**
A: 当前版本导出所有变更文件，后续版本可能支持过滤。

**Q: 已删除的文件会导出吗？**
A: 不会，已删除的文件（D 状态）会自动跳过。
